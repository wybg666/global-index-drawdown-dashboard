# 全球指数回撤与信号看板

一个在本机运行的 Python + 浏览器看板，集中查看固定清单中的 **28 个行情标的、27 个信号标的和 8 项宏观指标**。保留多周期技术信号、事件历史、宏观历史图和可选钉钉通知；不连接券商账户，不读取持仓，不执行交易。

> 这是个人研究与数据展示工具，非交易所、行情商或钉钉官方产品。“高点”指**报价参考日期向前 3 个日历月内的已取得高点**，不是历史最高点（ATH）；“近一年涨跌”也不是年初至今（YTD）。信号规则未经收益、胜率或实盘表现校准。

## 能做什么

- **行情与回撤**：最新价格、日涨跌、近一年涨跌、近 3 个月高点及日期、回撤百分比、来源和数据时点。
- **多周期信号**：15 分钟、60 分钟、日线的顶底结构识别，MA / RSI / ATR 等指标、证据、确认与失效状态。数据不足或尚未完成的 K 线会显示缺失/等待，不以日线冒充分钟线。
- **本地记录**：信号状态、变化事件、扫描结果与推送去重记录；新安装不附带原项目的个人状态。
- **宏观面板与历史图**：8 项指标及日 / 周 / 月 / 年视图。周、月、年取各期最后一个可用观测值，不是期间平均值；月度发布的数据不会变成真实日度数据。
- **扫描与通知**：手动扫描、分市场定时扫描，以及可选钉钉状态变化通知、A 股尾盘判断和收盘差异复核。默认不允许通知外发。

## 快速运行（Windows）

需要 **Python 3.11 或更高版本**、可访问相关公开数据站点的网络和一个现代浏览器。不需要 Node.js、npm、数据库服务或前端构建。

1. 下载项目并解压，进入能看到 `run.py`、`requirements.txt` 的项目根目录。
2. 在这个目录打开 PowerShell，建立独立环境并安装依赖：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

如果没有 `py` 命令，可将第一条改为 `python -m venv .venv`，并先确认 `python --version` 至少为 3.11。下面直接调用环境中的 Python，**不用执行 PowerShell 激活脚本**。

3. 启动：

```powershell
.\.venv\Scripts\python.exe -B run.py --open-browser
```

浏览器地址：[http://127.0.0.1:8780/](http://127.0.0.1:8780/)。依赖装好后也可以双击根目录的 **`start.bat`**，它优先使用 `.venv`，否则尝试 `py -3` / `python`；它不会自动安装依赖。

保持终端窗口打开，按 **Ctrl+C** 退出。仅关闭网页不会停止后台 Python 进程。第一次取数可能较慢；单个来源失败不代表其他模块也不可用，请先看卡片时点和错误提示。

### 启动选项

```powershell
# 端口被占用时换一个，不会停止其他占用端口的程序
.\.venv\Scripts\python.exe -B run.py --port 8781 --open-browser

# 不启动定时信号扫描；网页取数、手动扫描仍可使用
.\.venv\Scripts\python.exe -B run.py --no-scheduler --open-browser

# 明确允许通知外发；仍须在页面配置 Webhook 并启用通知
.\.venv\Scripts\python.exe -B run.py --allow-notifications --open-browser
```

默认启动会运行定时扫描，但**不会发通知**。`--no-scheduler` 不等于断网模式；页面刷新、历史查询或手动扫描仍会请求公开数据。程序仅监听 `127.0.0.1`，不是局域网共享服务，也不是登录即启动的 Windows 服务。

## 页面怎么用

1. 查看行情卡片上的价格、窗口高点、回撤及**行情数据时点**。页面生成时间只是整理结果的时间，不是所有市场共同的报价时间。
2. 点击刷新重新请求数据；市场休市、来源延迟或接口失败时，可能显示旧日期、缓存或部分数据，不能把它们当作实时行情。
3. 在扫描区域选择市场，点击“扫描（不推送）”执行手动扫描；页面按市场映射收盘阶段，不提供独立阶段选择。之后查看状态、证据和历史事件。数据缺失、待收盘确认与“没有信号”不是同一件事。休市日或最新数据日期不符合当日预期时，扫描可能全部跳过，这是保守处理，不代表所有标的都已成功评分；新安装首次历史为空也正常。
4. 在宏观区域查看指标及历史图。不同来源发布频率不同，央行储备可能是月度数据；折线缺口、缓存和来源错误需要一起阅读。
5. 通知是可选项，不配置也不影响看行情。不要为了“试运行”直接粘贴生产群机器人的 Webhook。

## 计算口径与数据源

### 回撤与历史窗口

```text
窗口起点 = 报价参考日期向前推 3 个日历月
窗口高点 = 窗口内已取得日线 high 的最大值
回撤百分比 = (当前价格 / 窗口高点 - 1) × 100%
```

窗口包含参考当天，不包含之后的 K 线；空窗口不会回退到全部历史。如果同日、同一参考日期的现价已创新高而日线尚未同步，该现价可作为显式的高点候选；报价与历史日期不一致导致的异常正“回撤”不会作为正常结果展示。

历史覆盖不足会标记为部分样本。`covered` 只表示已取数据的日期边界覆盖了窗口，**不保证中间每个交易日都完整**。这也不是区间最大回撤、总收益率或回测结果。近一年涨跌通常取一年前对应日期或此前最近可用收盘价；万得参考项可采用其官网给出的近一年收益口径。

| 数据 | 当前适配来源 |
| --- | --- |
| 中国 / 香港报价与日线 | 腾讯财经公开网页接口 |
| 中国 15 / 60 分钟线 | 新浪财经公开接口 |
| 美国、日韩日线；美国、香港、日韩分钟线 | Yahoo Finance chart 接口 |
| 万得小市值指数 | 万得指数官网公开快照、日线与区间收益接口 |
| 宏观与宏观历史 | 美国财政部、ChinaBond、KOFIA FreeSIS、Yahoo Finance、SAFE、TCMB EVDS3 等对应公开来源 |

部分接口并非稳定、有版本承诺的公开开发者 API；字段、网络限制、限流或数据授权可能变化。缺失会被显式报告，不保证永远可用。应遵守来源站点的使用条件；本项目不提供行情再分发授权。

### 扫描、日历与缓存

- 定时扫描按市场本地时区安排，A 股包含 14:55 尾盘与 15:10 收盘复核，美股包含收盘及延迟数据复核。只有程序持续运行、数据满足条件时才可能执行，不保证补齐所有错过的扫描。
- **内置日历维护范围为 2026 年**。跨年必须更新交易日历与运行时年份约束；未知年份会暂停自动扫描和收盘信号确认。非中国市场的调度并不等价于完整交易所日历，休市、临时休市和提前收市需要进一步维护，不能只依赖工作日判断。
- Yahoo 的当日日线若没有明确最终状态，可能保持“待确认”；新浪当天终端分钟线也会保守排除。来源延迟、缺失或未完成的 K 线会影响扫描，不能据此宣称实时完整覆盖。
- 行情缓存通常为 5 分钟，宏观快照 30 分钟，宏观历史 6 小时；页面还可能恢复本地浏览器缓存。旧缓存、部分数据、刷新失败的说明应连同时点一起看。
- 规则与阈值是研究逻辑，**没有已验证的胜率、盈利能力或适用性承诺**。保留“确认”字段不代表未来走势被确认，更不代表自动买卖指令。

## 可选钉钉通知

默认同时受到启动参数和页面设置控制：

1. 使用 `--allow-notifications` 启动，允许当前进程外发。
2. 在页面保存自己的钉钉群机器人 Webhook。
3. 如需常规自动通知，再打开页面通知总开关及需要的周期 / 状态开关。

**测试按钮会真实发送一条消息**：进程允许外发且提供有效 Webhook 后，即使常规通知总开关关闭，主动测试也可能发送。保存设置本身不会发送测试消息。手动扫描页面默认不自动发送通知；启用自动通知后，状态变化、尾盘判断等流程可能真实向群里外发。

安全与兼容性边界：

- 发送目标限定为 `https://oapi.dingtalk.com/robot/send`，不跟随重定向；网页写操作有本机来源和页面令牌检查。这不是面向公网的多用户认证系统，不要将服务反向代理到公网。
- 机器人关键字等安全策略必须与消息内容匹配，**不保证兼容所有机器人安全配置**。
- 当前没有根据钉钉加签 `secret` 自动生成动态签名的实现。若机器人启用了加签，需要另行接入动态签名；把带一次性 `timestamp/sign` 的地址保存下来不能保证持续可用。
- 可在启动前设置 `$env:INDEX_MONITOR_DISABLE_NOTIFICATIONS = "1"`，强制阻止通知外发。此开关独立于页面设置。
- 发布整理过程中**没有向真实群执行正式通知发送验证**。去重与发送状态不等于消息必达，不应当作紧急告警服务。

## 运行数据与隐私

Windows 默认运行目录为：

```text
%LOCALAPPDATA%\IndexDrawdownMonitor
```

其他系统使用对应用户数据目录；准确路径会在启动终端打印。需要隔离不同实例时，可在启动前指定项目目录之外的位置：

```powershell
$env:INDEX_MONITOR_DATA_DIR = Join-Path $env:LOCALAPPDATA "IndexDrawdownMonitor-Demo"
.\.venv\Scripts\python.exe -B run.py --no-scheduler
```

目录中可能包含通知设置、**明文 Webhook**、扫描/事件/推送历史和行情缓存。页面隐藏 Webhook 回显，不代表磁盘配置已加密。不要上传这个目录，也不要上传浏览器缓存导出、终端敏感日志或含密钥的截图。

此发布副本不带原个人设置、账号、通知凭据、缓存和历史状态。公开行情无需券商账号；访问来源站点时，对方仍会看到正常网络请求信息。项目中的 `.gitignore` 只是防误提交的辅助，**浏览器手动上传仍必须自己检查文件**。

## 已确认范围与限制

2026-10-10 的有限只读取数检查中，28 个行情标的和 8 项宏观快照均取得有效结果；SPY、日经、韩国综合指数、恒生指数、恒生科技指数、上证指数的代表性分钟源也取得了非空完成 K 线。窗口边界、错码拒绝和无效数值等检查另作过离线验证。

这些检查不代表全部市场的盘中长时间稳定运行，也不代表所有历史区间均已完整验证；没有验证交易执行、真实群正式发送或信号收益表现。这里记录的是该日期的检查范围，**不保证将来接口仍然可用**。

```text

├─ run.py                     # 启动入口

├─ .gitignore                 # 本地数据排除规则
├─ README.md
└─ index_monitor/
   ├─ indices.py / providers.py       # 指数行情与公共数据适配
   ├─ index_signals.py                # 信号计算
   ├─ index_signal_store.py           # 信号状态与事件记录
   ├─ index_signal_daily_push.py      # 判断快照、去重与推送流程
   ├─ runtime.py / notifier.py        # 调度、通知与设置
   ├─ macro_telemetry*.py             # 宏观快照与历史
   ├─ central_bank_gold.py / china_bond_yields.py
```
